# Visual Taste Lab · 视感实验室

> **AI 给你一张图。这里给你一双眼睛。**

一个**审美训练台**——不替你出图，教你看懂"为什么高级"，再把你验证过的审美变成可复现的选项。

## 为什么不直接问 AI 写 Prompt？

说实话：**论出图质量，AI 自己写的提示词和这个造的，差不多。** 新一代模型（Flux、MJ V7、Nano Banana、GPT-image）本身已经有审美了——你堆再多技术术语，它也只是做它本来就会做的事。

所以这个工具不跟 AI 比"谁的提示词更好"。它做的是 AI 一句话给不了的三件事：

- 👁 **教你看懂** —— 每个选项都标了"为什么有效"。AI 出完图就完了，不告诉你这张好在哪；学不到，下次还得靠运气。
- 🔁 **可复现** —— 每一项选择都明确、可追溯。AI 一句话每次结果都不同，你说不出怎么再来一张。
- 🧬 **抓共性** —— 上传一组你认可的图，反推它们共同的审美底层逻辑，做系列/IP/品牌视觉时保持一致。

## 这个工具做的事

把审美**拆开、讲清、变成选项**——重点不是替你生成，是训练你的眼睛。

### 三步工作流

```
步骤 1: DNA 预设卡片（14 个大师配置）
          ↓ 一键加载，自动填满 8 个维度
          ↓ 狄金斯 / 卢贝兹基 / 王家卫 / 库布里克 / 弗雷泽 ...

步骤 2: 8 维度微调面板
          ↓ 每个维度独立可选，像调音台的推子
          ↓ 镜头 × 胶片 × 灯光 × 调色 × 构图 × 质感 × 氛围 × 时代

步骤 3: SREF 代码 + 图片反推
          ↓ Midjourney 验证过的风格代码
          ↓ 上传好图 → 自动提取调色板 → 反推 Prompt 模板

          ↓ 锻造

      → 编译后的精确 Prompt（每项选择都对应一段技术语言）
```

每个预设对应一位电影摄影大师的完整视觉语言，自动填满所有 8 个维度：

- **Roger Deakins** — 狄金斯自然主义（《1917》）

- **Wong Kar-wai** — 王家卫霓虹夜
- **Stanley Kubrick** — 库布里克对称
- **Denis Villeneuve** — 维伦纽瓦史诗克制
- 以及古典伦勃朗、侘寂美学、粗野主义、慢电影、黄金时刻等

### 反推 Prompt 引擎

上传一张你喜欢的图：
- 🎨 自动提取 6 色调色板
- 🌡️ 判断色温（暖/冷/中性）和亮度
- 📋 附带 **@erenturkmen** 的精英级反推系统提示词（1.5k 赞 · 3.3k 书签 · 181k 浏览）
- 复制模板 → 扔给 ChatGPT/Claude + 图片 → 得到高精度 Prompt → 回来继续锻造

### 项目级审美一致性（Moodboard）

上传一组参考图 → 自动分析每张的亮度和饱和度 → 提取共同审美底层逻辑 → 自动建议匹配的 DNA 预设 → 输出统一的底层风格 Prompt。

做系列内容、IP、品牌视觉时最关键的能力。

## 技术来源

所有 Prompt 技术来源于公开创作者社区验证，非 LLM 凭空生成：

- **电影摄影**：designhero.tv — "prompt physics, not objects" 方法论 · Promptsera Cinematic Realism Blueprint · X/Twitter 摄影师社区
- **SREF 代码**：promptsref.com · @promptsref 每日更新
- **反推模板**：@erenturkmen — 跨平台通用反推系统提示词
- **Moodboard 分析**：原生 Canvas API 图像分析（调色板提取、亮度/饱和度统计）

## 使用方式

纯静态 HTML 文件，直接在浏览器打开即可：

```bash
open visual-taste-lab-forge.html
```

或在浏览器中直接打开文件。无需安装、无需服务器、无需 API key。

## 适用模型

生成的 Prompt 可直接用于：

- **Flux** (Pro / Dev / Schnell)
- **Midjourney V7**
- **Stable Diffusion 3 / SDXL**
- **DALL·E 3**
- 任何支持自然语言 Prompt 的图像生成模型

生成的 SREF 命令可直接在 Midjourney 中使用：`--sref <code> --v 7 --sv6`
